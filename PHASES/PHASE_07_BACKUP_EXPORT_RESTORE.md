# PHASE 7 — النسخ الاحتياطي والتصدير والاستعادة

**الحالة:** مطبقة في الشيفرة؛ لم يُشغّل اختبار Android/SAF فعلي في هذه البيئة.

## الوظائف
- تصدير ملف JSON بإصدار مخطط واضح يتضمن إعدادات التطبيق والعملات وسجل أسعار الصرف والمستودعات والأصناف والحركات والفواتير والمرتجعات والمصروفات والصناديق والجرد.
- اختيار موقع الحفظ والاستعادة عن طريق Android Storage Access Framework بدل طلب صلاحية تخزين واسعة.
- فرض حد للحجم 50 MiB والتحقق من إصدار النسخة ومعرّفات الصفوف والروابط والكميات والمبالغ والأرصدة قبل استبدال البيانات.
- تنفيذ الاستعادة بعد التحقق داخل معاملة Room واحدة وبترتيب حذف/إدخال يحافظ على اتساق العلاقات.
- دعم مخططات النسخ السابقة 1–3، مع قيم افتراضية لحقول تسوية المرتجعات التي أضيفت في الإصدار الثالث من مخطط النسخة.

## الملفات الرئيسية
`MizanBackupService.kt`, `BackupRestorePanel.kt`, `CommerceDao.kt`, `CurrencyConfigDao.kt`, `AppSettingsRepository.kt`.

## السلامة والخصوصية
- الاستعادة عملية استبدال كاملة وتعرض تأكيدًا قبل المتابعة.
- ملف JSON غير مشفر؛ يجب حفظه في موقع خاص وآمن وعدم مشاركته لأنه يحتوي بيانات مالية وتجارية.
- عمليات التحقق تمنع رفض النسخة غير المتسقة قبل حذف البيانات الحالية قدر الإمكان؛ لا توجد بعد عملية استرداد تلقائية إذا قام المستخدم باختيار ملف غير صحيح بعد تأكيده.
